GANDOM MAIN 8080 INTEGRATION RULES

1. Current 8080 UI is preserved.
2. No existing capability is deleted during transfer.
3. The 12 source capabilities are transferred as real code/evidence,
   not recreated as mock functionality.
4. Existing AI / Advertising / Revenue areas are not replaced yet.
5. Exchange receives a dedicated UI and chart integration point.
6. After transfer, an audit determines:
   - duplicate
   - incomplete
   - compatible
   - replaceable
   - obsolete/garbage
7. Deletion or replacement occurs only after audit evidence.
8. No fake PASS.
9. Every executable change requires syntax + runtime evidence.
10. Final 8080 integration is separate from the 12-section source.
