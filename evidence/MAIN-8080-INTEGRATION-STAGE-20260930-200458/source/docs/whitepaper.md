## 📜 خلاصه اجرایی (Executive Summary)

**گندم (Gandom)** یه بلاک‌چین غیرمتمرکز ایرانیه که با هدف ایجاد یه **ارز دیجیتال بومی** برای معاملات املاک، طلا، و خودرو طراحی شده. این پروژه با **۲۴ میلیارد سکه**، **۲۱ ماژول فعال**، و **۹۸ تست موفق**، آماده راه‌اندازی و رشد در بازارهای ایران و جهان است.

---

## 🎯 مشکل (Problem)

بازارهای ایران با مشکلات زیر مواجه هستن:

1. **عدم شفافیت:** معاملات املاک و طلا بدون ثبت رسمی
2. **واسطه‌های متعدد:** کمیسیون‌های بالا و زمان‌بر
3. **عدم دسترسی:** محدودیت برای سرمایه‌گذاران کوچک
4. **تحریم‌های مالی:** عدم دسترسی به سیستم‌های پرداخت جهانی
5. **تورم:** کاهش ارزش پول ملی

---

## 💡 راه‌حل (Solution)

گندم با استفاده از **تکنولوژی بلاک‌چین**، این مشکلات رو حل می‌کنه:

1. **شفافیت کامل:** همه تراکنش‌ها روی بلاک‌چین ثبت می‌شن
2. **حذف واسطه:** معاملات مستقیم بین خریدار و فروشنده
3. **تقسیم‌پذیری:** خرید کسر کوچکی از املاک و طلا
4. **غیرمتمرکز:** مقاوم در برابر تحریم‌ها
5. **ذخیره ارزش:** عرضه محدود ۲۴ میلیارد سکه

---

## 🔑 ویژگی‌های کلیدی (Key Features)

### ⛓️ بلاک‌چین هسته
- **الگوریتم اجماع:** PoW + Longest Chain
- **ساختار:** UTXO + Merkle Tree
- **زمان بلاک:** قابل تنظیم
- **۹۸ تست PASS** از ۱۰۰ تست

### 🔐 کیف پول امن
- کلید خصوصی ۲۵۶ بیتی (ECDSA)
- عبارت بازیابی ۲۴ کلمه‌ای (Mnemonic)
- رمزگذاری AES-256
- امضای دیجیتال

### 🔒 احراز هویت (KYC)
- اعتبارسنجی کد ملی (الگوریتم رسمی)
- تأیید شماره موبایل با OTP
- ۳ سطح احراز هویت
- رمزگذاری PBKDF2

### 🏪 سه بازار اصلی
- **املاک:** ۷ دسته (مسکونی، تجاری، اداری، صنعتی، کشاورزی، زمین، گردشگری)
- **طلا:** ۵ دسته (سکه، شمش، جواهرات، آلیاژ، سرمایه‌ای)
- **خودرو:** ۴ دسته (سبک، سنگین، موتور، برقی)

### 📊 صرافی غیرمتمرکز (DEX)
- سیستم سفارش (Order Book)
- استخر نقدینگی (Liquidity Pool)
- نمودار قیمت (Price Chart)
- فرمول AMM: `x * y = k`

### 🤖 هوش مصنوعی
- چت‌بات پشتیبانی
- تحلیل بازار و پیش‌بینی قیمت
- تشخیص تقلب
- تحلیل احساسات

### 🌐 شبکه غیرمتمرکز
- P2P Network
- DHT (Distributed Hash Table)
- IPFS (InterPlanetary File System)
- Tor (ناشناسی)
