# Contributing to GANDOM 2558

Thanks for your interest in GANDOM! We welcome contributions.

## What is GANDOM?

GANDOM is a living decentralized AI ecosystem. See README.

## Law 2558

All contributions must follow the Golden Mother Law 2558:

- NO_FAKE_PASS=1 (No fake success allowed)
- PASS_REAL_ONLY=1 (Only real execution counts)
- EVIDENCE_REQUIRED=1 (Every change needs SHA256 evidence)
- ROLLBACK_REQUIRED=1 (All changes must be revertible)

## How to Contribute

1. Fork the repo
2. Clone your fork
3. Create a branch
4. Make changes
5. Test locally with: bash GANDOM-BOOT.sh
6. Commit with clear message
7. Push and open a Pull Request

## Commit Prefixes

- feat: new feature
- fix: bug fix
- docs: documentation
- refactor: code restructure
- test: tests
- ci: CI/CD changes

## What NOT to Contribute

- Fake passes (violates Law 2558)
- Mock tests pretending to be real
- Hardcoded secrets
- node_modules or build artifacts

Open an issue on GitHub.
